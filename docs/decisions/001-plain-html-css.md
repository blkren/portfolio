# 001: Plain HTML and CSS, no framework

**Date:** 2026-10-26

**Options considered:** Plain HTML and CSS; a static site generator or framework

**Chosen:** Plain HTML and CSS

**Why:** No build step, nothing to install, and the pages load fast. Anyone reviewing the repo can read the source directly.

**Trade-off accepted:** Shared parts such as the header and contact links are repeated on each page rather than templated.
